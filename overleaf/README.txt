OVERLEAF UPLOAD INSTRUCTIONS
============================

1. This folder contains all necessary files for your IEEE Conference paper submission.

2. Files included:
   - main.tex: The LaTeX source code with your tables, figures, and text.
   - references.bib: Bibliography file.
   - figures/: Folder containing the generated plots.

3. How to use:
   a. Go to https://www.overleaf.com/
   b. Click "New Project" -> "Upload Project".
   c. Select the 'overleaf' folder from your computer (or zip it first and upload the zip).
   d. The project should compile automatically.

4. Note:
   - You may need to adjust author affiliation details in `main.tex`.
   - If you add more citations, update `references.bib`.
