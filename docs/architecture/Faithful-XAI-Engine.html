DeNovo Faithful XAI Engine

Three-stage validation ensuring LLM explanations match model decision process

Causal Consistency Test

  • • Remove claimed toxicophores
  • • Verify prediction drops ≥0.1
  • • Tests actual causal impact
  • • Uses CounterfactualGenerator

Counterfactual Test

  • • Generate 3 modified molecules
  • • Check prediction stability
  • • Verify explanation consistency
  • • Expensive - run once per sample

Grounding Test

  • • Compare claims to attention
  • • Adaptive threshold κ/N (κ=2.0)
  • • Validates atom indices match
  • • Prevents ungrounded claims
