DeNovo v2 Architecture: 4-Branch Multimodal Encoder

Multimodal fusion with Graph Transformer, SMILES, 3D Conformer, and Descriptors

4-Branch Architecture

  • • Graph Transformer (Graphormer, 256-dim)
  • • SMILES Branch (ChemBERTa-2, 768-dim)
  • • 3D Conformer Branch (SchNet, 128-dim)
  • • Descriptor Branch (RDKit 200, 64-dim)

Fusion & MoE

  • • Cross-attention fusion (8 heads)
  • • Mixture of 4 Experts with sparse gating
  • • Multi-task heads (12+ endpoints)
  • • Residual connections preserved

Pretraining & Loss

  • • GraphMAE on ZINC-15 (250K molecules)
  • • Asymmetric Loss (gamma_neg=4)
  • • Optuna 300-trial search
  • • Target AUROC: 0.918/0.924/0.931

Performance Targets

  • • TOX21: 0.918 (SOTA match)
  • • BBBP: 0.924 (SOTA match)
  • • ClinTox: 0.931 (SOTA match)
  • • Faithfulness: 1.000 (constrained)
