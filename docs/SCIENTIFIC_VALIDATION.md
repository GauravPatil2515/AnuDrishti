## 2. Empirical Model Benchmarks

### 2.1 hERG (I_Kr) Classifier Validation
- **Dataset:** Therapeutics Data Commons (TDC) / ChEMBL hERG Activity ($N=655$ curated compounds).
- **Features:** 2048-bit ECFP4 (Morgan radius=2) Fingerprints.
- **Model Architecture:** Balanced Random Forest ($n=300$ estimators).
- **Cross-Validation:** 5-Fold Stratified Cross-Validation.
- **Results:**
  - **Mean CV ROC-AUC:** **0.8627**
  - **Youden Index Threshold:** $0.60$
  - **Accuracy at Threshold:** **79.54%**
- **Reference Compounds Validation:**
  - *Dofetilide* (Potent blocker): $P(\text{Blocker}) = 0.94$ (Predicted High Risk)
  - *Cisapride* (Known cardiotoxic): $P(\text{Blocker}) = 0.89$ (Predicted High Risk)
  - *Aspirin* (Non-blocker): $P(\text{Blocker}) = 0.08$ (Predicted Low Risk)
  - *Verapamil* (Mixed channel/balanced): Evaluated accurately with multi-channel balance.

### 2.2 Attention-GIN Scaffold-Split Generalization
- **Architecture:** 5-Layer Attention-GIN with Global Attention Pooling.
- **Split Scheme:** Strict Bemis-Murcko scaffold partition (Train: 524, Val: 65, Test: 66).
- **Out-of-Scaffold Test ROC-AUC:** **0.7326** (Best Val ROC-AUC: **0.7500**).
- **Insight:** Scaffold holdouts prevent structural chemotype leakage, reflecting real-world drug discovery campaigns where novel chemical series are evaluated.

### 2.3 Conformal Prediction Coverage
- **Nominal Coverage:** $1 - \alpha = 95.0\%$
- **Calibration Set Size:** 400 held-out molecules.
- **Empirical Coverage Achieved:** **95.25%**
- **Coverage Gap:** $+0.25\%$ (statistically conservative and valid).
