Attention-GINet Architecture
How Attention-GINet Works:
  1. Input: SMILES string converted to molecular graph via RDKit (atoms as nodes, bonds as edges)
  2. Node Embedding: Atom features (type, chirality) and bond features (type, direction) are embedded into dense vectors
  3. Message Passing (5 GINEConv layers): Each layer aggregates information from neighbors using edge-aware messages, then updates node representations via MLP
  4. Global Attention Pooling: A gate network computes importance scores for each atom, normalized via softmax per molecule to get attention weights α_i
  5. Readout: Weighted sum of node features using attention weights produces graph-level representation
  6. Prediction: MLP maps graph representation to task-specific outputs (toxicity predictions)
  7. Explainability: Attention weights α_i indicate atom importance for prediction, mapped to substructures for interpretation
GINEConv Message Passing Mechanism
GINEConv Message Passing Details:
  1. Message Function: For each edge (i,j), compute m_ij = h_j^(l-1) + e_ij^(l)
    • h_j^(l-1): Previous layer's node feature for neighbor j
    • e_ij^(l): Edge feature embedding (bond type + bond direction)
  2. Aggregation: Sum all incoming messages: m_i = Σ_j∈N(i) m_ij
  3. Update Function: h_i^(l) = MLP^(l)(h_i^(l-1) + m_i)
    • Combines original node features with aggregated neighborhood information
    • Passed through a multi-layer perceptron (MLP)
  4. Edge Features: GINE explicitly incorporates edge information unlike standard GIN
Global Attention Mechanism
How Attention Works in Attention-GINet:
  1. Gate Network: Each node's final features h_i^L are passed through a small MLP to produce importance scores z_i
  2. Softmax Normalization: Scores are converted to attention weights α_i using softmax, ensuring ∑α_i = 1 for each molecule
  3. Weighted Aggregation: Graph representation h_G = ∑α_i · h_i^L is a weighted sum where important atoms contribute more
  4. Interpretability: High attention weights α_i indicate atoms that are particularly important for the prediction
  5. Connection to Explainability: These weights are mapped to molecular substructures via RDKit to generate human-interpretable explanations
Feature Engineering Pipeline
Feature Engineering in DeNovo:
  1. SMILES Processing: Input validation, canonicalization, and constraint checking using RDKit
  2. Parallel Feature Extraction:
    • RDKit Descriptors: 200+ physicochemical and topological properties (MW, LogP, TPSA, etc.)
    • Morgan Fingerprints: 2048-bit circular fingerprints capturing local atomic environments (radius=2)
    • ChemBERT Embeddings: 768-dimensional transformer-based embeddings capturing semantic molecular similarities
  3. Feature Fusion: Concatenation of all feature types creates rich, multi-representation vectors (~3016 dimensions)
  4. Parallel Processing Path:
    • Traditional ML models (XGBoost) use the concatenated feature vector
    • GNN pathway converts SMILES to molecular graph, processes through Attention-GINet layers
    • Produces graph-level embedding plus atom-level attention weights for explainability
  5. Model Ensemble: Predictions from both pathways can be combined for improved robustness

Key Mathematical Formulations

1. Attention-GINet Core Equations

Node Initialization:
h_i^(0) = x_emb^(1)(x_i^0) + x_emb^(2)(x_i^1)
where x_i^0 = atom type (119-dim), x_i^1 = chirality tag (3-dim)
GINEConv Message Function:
m_ij^(l) = h_j^(l-1) + e_emb^(1)(e_ij^0) + e_emb^(2)(e_ij^1)
where e_ij^0 = bond type (5-dim), e_ij^1 = bond direction (3-dim)
GINEConv Update:
h_i^(l) = MLP^(l)( h_i^(l-1) + Σ_{j∈N(i)} m_ij^(l) )
Global Attention Pooling:
z_i = MLP_gate(h_i^L)
α_i = exp(z_i) / Σ_{j∈𝒢} exp(z_j)
h_G = Σ_{i∈𝒢} α_i · h_i^L
Prediction Head:
h_F = W_2 σ(W_1 h_G + b_1) + b_2
where σ = Softplus(β) = (1/β)log(1 + e^(βx))
ŷ = σ(h_F) (for binary classification)

2. Loss Functions

Binary Cross-Entropy (with class weighting):
L = -(1/N) Σ_i [ w_p · y_i · log(σ(ŷ_i)) + (1-y_i) · log(1-σ(ŷ_i)) ]
where w_p = (# negatives) / (# positives) for imbalance handling
Mean Squared Error (Regression):
L = (1/N) Σ_i (y_i - ŷ_i)^2

3. Optimization (Adam)

Moment Estimation:
m_t = β₁m_(t-1) + (1-β₁)g_t
v_t = β₂v_(t-1) + (1-β₂)g_t²
Bias Correction:
m̂_t = m_t / (1-β₁^t)
v̂_t = v_t / (1-β₂^t)
Parameter Update:
θ_t = θ_(t-1) - (η / (√v̂_t + ε)) · m̂_t
where η = learning rate, ε = small constant for numerical stability

4. Faithfulness Score (Explainability)

Faithfulness Score:
F = √(G × C)
Geometric mean of Grounding (G) and Causal (C) scores
Grounding Score:
G = corr(α, A)
Correlation between attention weights α and human-annotated toxicity annotations A
Causal Score:
C = 1 - (1/M) Σ_m |Δp_m| · I(α_m < τ)
Average prediction change when perturbing low-attention atoms
